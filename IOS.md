# Приложение для iPhone

В папке `ios/` лежит готовый проект Xcode: то же приложение внутри iOS-оболочки (Capacitor).
Веб-часть уже собрана и лежит в проекте, поэтому для установки на свой iPhone нужен только Xcode.

## Установка на свой iPhone (бесплатно)

1. **Скачай проект.** На GitHub: зелёная кнопка **Code → Download ZIP**, распакуй.
2. **Открой** файл `ios/App/App.xcodeproj` двойным щелчком — откроется Xcode.
   Первый раз Xcode пару минут скачивает Capacitor (строка состояния вверху) — дождись.
3. **Войди своим Apple ID в Xcode:** меню **Xcode → Settings → Accounts → «+» → Apple ID**.
4. **Подпись:** слева нажми на синий значок **App** → в центре вкладка **Signing & Capabilities** →
   поставь галочку **Automatically manage signing** и выбери **Team** — «Твоё имя (Personal Team)».
   Если Xcode пишет, что идентификатор занят, поменяй **Bundle Identifier**, например
   на `ru.pokarmanuapp.budget.stasya`.
5. **Подготовь iPhone:**
   - подключи его к Mac кабелем, на телефоне нажми **«Доверять»**;
   - включи режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить,
     телефон перезагрузится (пункт появляется после того, как iPhone подключён к Xcode).
6. **Запусти:** вверху Xcode выбери свой iPhone в списке устройств и нажми **▶** (или Cmd+R).
7. **Первый запуск:** iPhone скажет «Ненадёжный разработчик». Открой
   **Настройки → Основные → VPN и управление устройством → Apple Development: твоя почта → Доверять**.
   Запусти приложение снова.

### Ограничения бесплатной установки
- Через **7 дней** приложение перестанет открываться — подключи iPhone и снова нажми ▶ в Xcode (данные сохранятся).
- Раздать приложение другим людям так нельзя — для этого нужен платный Apple Developer Program и App Store.

## Обновление веб-части (для разработки)

После изменений в коде:

```bash
npm ci
npm run build:ios   # собирает веб-часть с относительными путями и копирует её в ios/
```

Затем в Xcode снова ▶.
